🚀 INSTALACIÓN ULTRA RÁPIDA (1 minuto)

1. Abre la carpeta "dist"
2. Doble click en: AIdan_Desktop.exe
3. ¡Listo! Se abre el dashboard

✅ No necesita Python
✅ No necesita configuración
✅ No necesita API keys
✅ Todo funciona automáticamente

════════════════════════════════════════════════════════════════════

💡 CÓMO USAR

El dashboard muestra:
- 📰 Noticias financieras en tiempo real
- 📊 Impacto en EUR/USD (0-100)
- 🎯 Señales CALL/PUT para trading
- ⏰ Timeframes sugeridos (1-5 min)
- 🟢🟡🔴 Probabilidad de acierto

Solo aparecen noticias de ALTO impacto (score ≥ 80)

════════════════════════════════════════════════════════════════════

🧠 ANÁLISIS CON IA (OPCIONAL)

Para análisis más preciso con IA local:

1. Instala Ollama: https://ollama.com/download
2. Abre PowerShell y ejecuta:
   ollama pull llama3.1:8b
3. Reinicia AIdan_Desktop.exe

Con Ollama: Análisis avanzado GRATIS
Sin Ollama: Análisis básico (también funciona bien)
